# Decentralized Lottery Smart Contract

## Description:
A decentralized lottery system written in Solidity. Users can buy tickets, and after a timed round, a random winner is selected to receive the prize pool.

## Features
- Ticket purchase at fixed price
- Multiple tickets per player
- Time-based rounds
- Random winner selection (Chainlink VRF or simulation)
- Prize distribution

## How to Run
Use [Remix IDE](https://remix.ethereum.org/):
1. Copy `Lottery.sol` into Remix
2. Compile with Solidity 0.8.x
3. Deploy using Injected Provider (e.g., MetaMask)

## Testing
Test by:
- Buying tickets from multiple addresses
- Advancing the round time
- Triggering winner selection
